製作 AI 行銷影片，可以依「選題 → 整理視覺素材 → 寫分鏡與製作鏡頭 → 剪輯初稿 → 檢查輸出」五步進行。先決定影片要回答哪一個商品問題，再使用 AI 製作確實需要的畫面，不必先生成一堆素材才開始想故事。

每一步留下可檢查的成果：一句影片任務、一份素材包、一張分鏡表、一支粗剪，以及一份修改紀錄。卡關時回到對應成果，就比較容易定位缺少的是資料、畫面還是剪輯。

以下以假設的通勤包練習，並非客戶案例或實測成效。尺寸、容量、夾層與材質，都需要換成自己商品的真實資料；60 秒是示例長度，不是所有影片的最佳長度。

## 第一步：AI 行銷影片要先選什麼題目？

先選一個受眾在意、而且你有資料回答的問題。第一支影片可以只介紹一個功能，不用同時講品牌故事、所有規格與全部顏色。

通勤包示例的任務是：「讓每天帶筆電通勤的人，看懂這款包的內層收納方式。」

把題目寫成三句：

- 給誰看：每天帶筆電與隨身物品通勤的人。
- 看懂什麼：實際物品如何放進對應的夾層。
- 下一步：到商品頁核對尺寸與其他角度。

如果沒有實際放入筆電的資料，就先改成內層結構介紹，或補拍操作。腳本不能先承諾容量，再期待 AI 生成一個看起來放得下的畫面。

**這一步留下：一句可核對的影片任務。**

## 第二步：先準備哪些商品與視覺素材？

先整理能確認商品外觀與功能的真實資料，再安排人物與場景。最低素材包應能回答「是哪件商品」「要展示什麼」「依據是什麼」。

<div className="guide-table-scroll">

| 資料 | 用途 | 缺少時怎麼處理 |
|---|---|---|
| 同款商品全貌與細節原照 | 核對包型、顏色、標誌、內袋 | 補拍或縮小鏡頭範圍 |
| 已確認的尺寸與文案 | 決定可以說哪些商品資訊 | 標記待確認，暫不寫入影片 |
| 相關操作影片 | 交代開合、放入、拿取 | 補真拍，或改成靜態結構說明 |
| 場景與風格參考 | 統一畫面方向 | 先選少數能完成任務的場景 |
| 素材來源與使用條件 | 確認製作及發布範圍 | 未確認的素材先不進正式輸出 |

</div>

通勤包可以先用「桌面整理」與「出門通勤」兩個場景。外觀、內層及操作必須對得上同款商品，不把不同包型混成一支介紹影片。

需要整理檔案時，可使用 [商品影片資料包與需求模板](https://chaozhibai.ai/insights/product-video-brief)。

**這一步留下：一份有版本與用途的素材包。**

## 第三步：分鏡怎麼寫，哪些鏡頭才需要 AI？

每鏡先寫畫面任務，再決定素材來源與預計秒數。展示實際功能時使用可核對的素材；AI 可以協助想像情境或視覺銜接，但不能代替功能證據。

以下是 60 秒的段落分配，不代表每段只能使用一個鏡頭：

<div className="guide-table-scroll">

| 時間 | 段落任務 | 建議素材 | 檢查重點 |
|---|---|---|---|
| 0–8 秒 | 桌面通勤物品，帶出整理需求 | 真拍或不暗示容量的情境畫面 | 看得懂這支片要回答什麼 |
| 8–23 秒 | 認識包型、開口與內層 | 商品全貌、細節真拍 | 同款、同色、結構一致 |
| 23–43 秒 | 展示實際收納 | 真實放入與拿取 | 物品規格、操作前後能核對 |
| 43–54 秒 | 呈現出門使用情境 | 真拍或經核對的情境段 | 不改變商品、人物比例 |
| 54–60 秒 | 商品名稱與查詢方向 | 核准圖片與後製文字 | 連結、名稱與資訊正確 |

</div>

|---|---|---|---|---|---|---|
| 01 |  |  |  |  |  |  |
| 02 |  |  |  |  |  |  |
| 03 |  |  |  |  |  |  |

需要生成的單鏡，先從簡單動作開始，檢查可用再加下一鏡。可參考 [商品單鏡 Prompt 與修改示範](https://chaozhibai.ai/insights/ai-product-video-prompt)。

**這一步留下：分鏡表，以及通過基本核對的鏡頭素材。**

## 第四步：素材都有了，怎麼剪成一支片？

先照畫面任務排出完整順序，再補字幕、旁白與音樂。第一輪要解決的是觀眾能不能看懂，不是特效夠不夠多。

例如「桌上有筆電 → 包包已關上 → 人物出門」少了收納過程。若影片要回答怎麼放，應補上實際放入的畫面；沒有可靠素材，就修改題目或使用靜態結構說明。

接鏡時先檢查：

1. 前後的包包方向、顏色與標誌是否一致。
2. 手是否突然換邊，桌面物品是否無故消失。
3. 每一段字幕是否有足夠閱讀時間。
4. 旁白是否補充資訊，音樂是否蓋住人聲。
5. 結尾是否只有一個與內容相符的下一步。

若內容過長，先刪除與任務無關的鏡頭。不要只把全部素材加速，讓需要辨認的操作也一閃而過。

**這一步留下：一支能從頭看完的粗剪。**

## 第五步：輸出前後，怎麼確認影片能用？

先核對商品與資訊，再檢查觀看體驗。匯出後用實際觀看裝置完整播放，不能只看剪輯軟體的預覽窗。

<div className="guide-table-scroll">

| 檢查項目 | 怎麼看 | 發現問題時 |
|---|---|---|
| 商品正確 | 比較原照與影片開頭、中間、結尾 | 替換錯誤鏡頭或回到真拍 |
| 操作完整 | 靜音看一次，確認前後關係 | 補操作或調整腳本 |
| 字幕可讀 | 用手機與發布預覽檢查 | 改位置、長度或停留時間 |
| 聲音清楚 | 完整聽一次 | 調整人聲、音樂與切點 |
| 資訊與權限 | 核對名稱、連結、規格及素材紀錄 | 未確認部分先不發布 |

</div>

修改紀錄寫成「00:12 包型與原圖不同」「00:25 字幕遮住袋口」，並標註版本。修正後照同一張表再看一次。

**這一步留下：可發布的輸出檔與具體修改紀錄。**

## 可以請 AI 幫忙整理腳本嗎？

可以，但先提供已確認的商品資料，要求缺少資訊時標記待補。下面是給聊天 AI 整理企劃的指令，不是直接貼進影片生成工具的鏡頭 Prompt。

> 請依我提供的資料，整理一支商品介紹影片的腳本與分鏡。商品：【填寫】；受眾：【填寫】；這次只回答：【填寫】；已確認資訊：【填寫】；現有照片與操作素材：【填寫】；使用位置：【填寫】；預計長度：【填寫】；看完的下一步：【填寫】。請列出鏡號、畫面任務、字幕、素材來源、預計秒數及核對依據。沒有資料的功能、容量、效果與價格請標待補，不自行編造；需要真實操作的鏡頭請另外列出補拍清單。
